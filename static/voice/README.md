# نصّ التسجيل الصوتي 🎙️

سجّل هذه المقاطع بصوتك وضعها في هذا المجلد بالأسماء المحددة تماماً.
الصيغ المقبولة: `.mp3` أو `.m4a` أو `.wav` أو `.ogg` أو `.aac`.

أي مقطع تسجّله يُستخدم فوراً. المقاطع الناقصة يقرؤها الصوت الآلي كالمعتاد،
فتقدر تسجّل واحداً واحداً على راحتك.

| اسم الملف | النص الذي تقوله |
|---|---|
| `reveal` | جرت القرعة. اطّلع على دورك سراً، ولا تُخبر أحداً. |
| `night` | حلّ الليل. على الجميع أن يغمض عينيه. |
| `killers` | ليفتح القتلة أعينهم، واتفقوا على ضحية هذه الليلة. |
| `detective` | ليُغلق القتلة أعينهم. ليفتح المحقق عينيه، واستفسر عن شخص واحد. |
| `doctor` | ليُغلق المحقق عينيه. ليفتح الطبيب عينيه، واختر شخصاً لحمايته. |
| `morning` | ليُغلق الطبيب عينيه. ليفتح الجميع أعينهم. |
| `kill_success` | عملية قتل ناجحة. |
| `kill_failed` | عملية قتل فاشلة. لم يسقط أحد الليلة. |
| `vote` | ابدأوا النقاش والتصويت، أو اختاروا عدم التصويت. |
| `eliminated` | صوّت اللاعبون، وتم استبعاد أحدهم من اللعبة. |
| `no_elimination` | لم يُستبعد أحد اليوم. |
| `win_killers` | انتهت اللعبة. فاز القتلة! |
| `win_citizens` | انتهت اللعبة. فاز المواطنون! |

## لماذا بلا أسماء أو أرقام؟
اسم الضحية ورقم الليلة يتغيران كل جولة، فلا يمكن تسجيلهما مسبقاً.
النظام يعرضهما على الشاشة بخط كبير، والصوت يقول الجملة الثابتة فقط.

`morning` و `kill_success`/`kill_failed` يُشغَّلان متتابعين في الصباح،
فسجّلهما منفصلين ولا تترك صمتاً طويلاً في نهاية أي مقطع.

## نصائح
- سجّل في مكان هادئ، بنبرة بطيئة ومسرحية — أنت راوي اللعبة.
- اقتطع الصمت من بداية ونهاية كل مقطع.
- **من الآيفون**: تطبيق «المذكرات الصوتية» ينتج ملف `.m4a` مدعوم مباشرة.
  سجّل، ثم شارك الملف إلى الماك، وأعد تسميته بالاسم المطلوب.

## مقطعان اختياريان لوضع القاتل الواحد

عند اختيار **قاتل واحد**، يبحث النظام عن هذين المقطعين أولاً، وإن لم يجدهما
استخدم مقطعَي الجمع المعتادين (`killers` و `detective`) — فتسجيلهما اختياري تماماً.

| اسم الملف | النص |
|---|---|
| `killers_one` | ليفتح القاتل عينيه، واختر ضحية هذه الليلة. |
| `detective_one` | ليُغلق القاتل عينيه. ليفتح المحقق عينيه، واستفسر عن شخص واحد. |
