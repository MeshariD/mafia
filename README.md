# مافيا 🎭 — لعبة القاتل الليلي

لعبة ويب جماعية بالعربية: **قاتل أو قاتلان + طبيب + محقق + مواطنون**.
المضيف ينشئ غرفة ويشارك رابطها (نسخ · واتساب · تيليجرام · أي تطبيق)،
وكل لاعب يفتح الرابط من جواله، والنظام يتولّى القرعة والسرد والليل والتصويت.

## سير اللعبة
1. **الانضمام** — المضيف ينشئ غرفة ويشارك الرابط، وكل لاعب يسجّل اسمه.
2. **القرعة** — توزيع عشوائي: قاتل أو قاتلان 🔪، طبيب 🩺، محقق 🕵️، والباقي مواطنون 🧑. كل لاعب يرى بطاقته سراً.
3. **الليل** — «الجميع يغمض عينه»:
   - القتلة يفتحون أعينهم، ولهم **محادثة سرية** بينهم، ويتفقان على الضحية.
     (بقاتل واحد يختار وحده بلا محادثة.)
   - المحقق يستفسر عن شخص واحد، فيخبره النظام فوراً: **قاتل** أو **ليس قاتلاً**.
   - الطبيب يحمي شخصاً واحداً (بما فيه نفسه)، ولا يكرر نفس الشخص.
4. **الصباح** — «عملية قتل ناجحة» مع اسم الضحية، أو «عملية قتل فاشلة».
5. **التصويت** — ٣ دقائق نقاش وتصويت، مع خيار **عدم التصويت**. يُستبعد الأكثر أصواتاً **دون كشف دوره**.
6. تتكرر الدورة حتى نهاية اللعبة.

## شروط الفوز
- **المواطنون** يفوزون بخروج كل القتلة.
- **القتلة** يفوزون عندما يتساوى عددهم مع عدد بقية اللاعبين الأحياء.

## الدخول والدعوة
1. **تسجيل الدخول** — اللاعب يكتب اسمه فقط (بدون كلمة مرور)، ويُحفظ الاسم في متصفحه فلا يعيد كتابته.
2. **إنشاء غرفة** أو **الانضمام برمز**. ومن فتح رابط دعوة يجد زراً مباشراً: «انضم إلى الغرفة».
3. **إرسال الدعوة** — من داخل الغرفة، بطاقة **«أرسل الدعوة لباقي اللاعبين»**:
- **نسخ** الرابط إلى الحافظة.
- **واتساب** — يفتح واتساب برسالة جاهزة فيها رمز الغرفة والرابط.
- **تيليجرام** — نفس الشيء عبر تيليجرام.
- **مشاركة…** — تظهر على الجوال فقط، وتفتح قائمة المشاركة في النظام (أي تطبيق: رسائل، بريد، تويتر…).
- أو أعطهم **رمز الغرفة** المكوّن من ٤ خانات ليُدخلوه بعد تسجيل الدخول.

من فتح رابط الغرفة وهو منضمّ إليها أصلاً، يعود مباشرة إلى مكانه في الجولة دون إعادة انضمام.

## حفظ اللعبة
- **من جهة اللاعب**: هويتك محفوظة في المتصفح، فلو أغلقت الصفحة أو انقطع النت، أعد فتح نفس الرابط فتعود إلى دورك ومكانك في الجولة.
- **من جهة الخادم**: كل الغرف تُحفظ في `DATA_DIR/rooms.json` (افتراضياً مجلد `data/`)، وتُستعاد تلقائياً عند إعادة تشغيل الخادم مع مهلة سماح للاعبين كي يعودوا.
- تُحذف الغرفة تلقائياً بعد **٦ ساعات** من الخمول.

## الأوقات والقواعد القابلة للضبط
تُضبط عند إنشاء الغرفة، ويستطيع **المضيف تعديلها داخل غرفة الانتظار** قبل البدء
فتُطبَّق فوراً على شاشات الجميع:

| الإعداد | الافتراضي | المدى |
|---|---|---|
| عدد القتلة | قاتلان | قاتل واحد أو قاتلان |
| وقت القتلة لاختيار الضحية | ٣٠ ثانية | ١٠–٣٠٠ ثانية |
| وقت المحقق للاستفسار | ٣٠ ثانية | ١٠–٣٠٠ ثانية |
| وقت الطبيب للحماية | ٣٠ ثانية | ١٠–٣٠٠ ثانية |
| مدة النقاش والتصويت | ٣ دقائق | ٣٠–٩٠٠ ثانية |
| حماية الطبيب | لا يحمي نفس الشخص ليلتين متتاليتين | أو مرة واحدة طوال اللعبة |

بقية اللاعبين يرون الإعدادات للاطلاع فقط. القيم خارج المدى تُقصّ تلقائياً.

## تفاصيل أخرى
- **التعادل في التصويت** أو تغلّب «عدم التصويت» ⇐ لا يُستبعد أحد.
- إذا اختلف القاتلان حتى انتهاء الوقت، يُختار أحد اختياريهما عشوائياً.
- **صوت الراوي يعمل تلقائياً** عند فتح اللعبة، ولا يحتاج تفعيلاً. إن منعه المتصفح قبل أول
  تفاعل، تظهر لافتة واضحة بزر «🔊 فعّل الصوت» تُعيد تشغيل الجملة الحالية بعد الضغط.
  زر 🔊/🔇 أعلى الشاشة يكتم الصوت، ويُحفظ اختيار كل لاعب في متصفحه.
  الأصوات مسجّلة بصوت المضيف — انظر [static/voice/README.md](static/voice/README.md).
- **الحد الأدنى يتبع عدد القتلة**: ٥ لاعبين بقاتل واحد، و٦ بقاتلَين. والأفضل من ٨ إلى ١٢.
  السبب: يلزم مواطنان على الأقل بعد القتلة والطبيب والمحقق، وإلا انتهت الجولة فور أول قتل ناجح.
- بعد استفسار المحقق يحصل على **١٢ ثانية ثابتة** لقراءة النتيجة مهما تبقّى من وقت المرحلة.
- **المضيف** يستطيع تخطّي أي مرحلة، وإعادة اللعبة من البداية في أي وقت (بتأكيد)،
  فيعود الجميع إلى غرفة الانتظار وتُوزَّع الأدوار من جديد.

## التشغيل محلياً
```sh
./run.sh                 # http://localhost:8000
PORT=8123 ./run.sh       # منفذ آخر لو كان 8000 مشغولاً
```
بدون أي مكتبات خارجية — Python 3 فقط. للعب على نفس شبكة الواي‑فاي،
أعطِ أصدقاءك `http://<عنوان-جهازك-المحلي>:8000`.

## النشر — رابط أونلاين دائم
### Render (Blueprint جاهز)
1. أنشئ مستودعاً جديداً على GitHub (خاصاً أو عاماً).
2. من داخل هذا المجلد:
   ```sh
   git remote add origin https://github.com/<حسابك>/mafia.git
   git push -u origin main
   ```
3. Render → **New** → **Blueprint** → اختر المستودع. ملف `render.yaml` يتكفّل بالباقي.
4. الرابط الناتج (مثل `https://mafia.onrender.com`) هو ما تشاركه مع اللاعبين.

**الخطة المجانية مقابل المدفوعة:**
- **free**: تكفي تماماً لجلسة لعب — الخدمة تبقى مستيقظة ما دام أحد يلعب. لكن الغرف تضيع
  عند إعادة النشر أو بعد ١٥ دقيقة من الخمول التام (الخدمة تنام والملفات تُمسح).
- **starter** (~٧$ شهرياً) مع قرص دائم: الغرف محفوظة فعلياً عبر كل إعادة تشغيل ونشر.
  فعّلها بتغيير `plan` إلى `starter` وإزالة التعليق عن كتلة `disk` في `render.yaml`.

### أي استضافة تدعم Docker
`Dockerfile` جاهز ويستمع على متغير البيئة `PORT`، ويحفظ الحالة في `DATA_DIR`.

## ملاحظة أمنية
ملف `rooms.json` يحتوي رموز جلسات اللاعبين بنص صريح. هذا مقبول للعبة جماعية،
لكن لا تشارك الملف ولا تجعل مجلد `data/` متاحاً للعامة (وهو مستثنى في `.gitignore`).
